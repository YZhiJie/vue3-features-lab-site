泛型组件 ​

这是什么 ​

<script setup generic="...">（Vue 3.3+）让组件拥有自己的类型参数： 父组件传入什么样的 props，T 就被推导成什么类型 —— props、emits、 函数签名里的 T 全部联动，回调里拿到的是精确类型而不是 any。

vue
<!-- SelectableList.vue -->
<script setup lang="ts" generic="T">
defineProps<{ items: T[] }>()
const emit = defineEmits<{ (e: 'select', value: T): void }>()
</script>
vue
<!-- 父组件：传 string[] 时 T = string，传 Employee[] 时 T = Employee -->
<SelectableList :items="tags" @select="v => ..." />
<SelectableList :items="employees" @select="v => ..." />

类型是怎么推导的 ​

  1. 父组件写 :items="tags"，tags 是 string[] → T 被绑定为 string；
  2. 组件内所有 T（items、emit 载荷、暴露函数的参数）同步替换成 string；
  3. 父组件的 @update:model-value 回调参数因此拿到精确类型 —— 全程零手写泛型标注。

编辑器里把鼠标悬停在本演示的 pickedTag / pickedEmployee 上可以直接 看到推导结果；在 :label 回调里输入 item. 还能弹出补全。

generic 属性怎么写 ​

写法说明
generic="T"单个类型参数，无约束（本演示用，为了兼容 string 与对象两种数组）
generic="T extends { id: number }"带约束：items 必须是含数字 id 的对象数组，传错形状编辑器标红
generic="T, U"多个类型参数，逗号分隔
generic="T extends X = DefaultT"带默认值的类型参数

与 any 的区别 ​

items: any[]items: T[]
回调参数类型any（类型检查关闭）精确推导（如 Employee）
写错字段名运行时才炸编辑器立刻标红
补全没有有
约束能力无extends 约束输入形状

泛型是纯编译期概念：运行时不存在 T，零开销。

常见坑（真实踩坑记录） ​

  • 模板里不能显式实例化泛型：<SelectableList<Employee> ... /> 不被 支持 —— 泛型只能从 props 推导；想让 T 稳定，就保证 items 的类型标注 完整（别写 any[]）。
  • generic 是字符串属性：里面写不了模板语法，多参数用逗号、约束用 extends、默认值用 = —— 与 TS 类型参数语法一致，只是整体包在引号里。
  • props/emits 引用了未声明的类型参数：generic 里只写了 T，props 里 却用了 U → 编译报错；每个出现的类型参数都必须在 generic 里声明。
  • any 起步要舍得删干净：any 会顺着调用链污染类型 —— 练习版只要 漏改一个 any（比如回调参数），父组件拿到的就还是 any，前功尽弃。
  • 运行时没有 T：想根据 T 写不同运行时逻辑做不到（类型擦除）； 运行时分支请基于值本身判断（如 typeof item === 'string'， 本组件的展示兜底就是这么写的）。
